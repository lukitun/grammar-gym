# Grammar Gym

Free English grammar exercises for non-native speakers. No paywall, no signup, no tracking.

Static site — pure HTML/CSS/JS, no build step. Open `index.html` or serve the folder.

## Topics
Articles · Verb Tenses · Prepositions · Conditionals · Modal Verbs · Comparatives · Reported Speech

## Add exercises
Edit `exercises.js`. Each question is `mc` (multiple choice) or `fill` (typed). `fill` answers accept an array of variants.

## Deploy
Any static host. Configured for Netlify (`netlify.toml`, publish root).
